# 试课学生快速排课功能（试运行说明）

## 一、功能目的

学校的试课通常为一个 3 小时体验包，由两节各 90 分钟的课程组成。常规的 Robotics、Coding 等课程有固定班级，但 AI、3D、VEX IQ、VEX V5 等课程的时间安排较灵活，因此系统现在采用两种排课方式，既保留原有班级逻辑，也支持灵活安排。

## 二、两种排课方式

### 1. Existing class（加入现有课程）

适合已有固定班级的课程。管理员选择科目和日期后，系统列出当天可加入的课程、教室、时间及剩余名额。

### 2. Flexible trial slot（灵活试课时段）

目前用于 AI、3D、VEX IQ 和 VEX V5。管理员选择日期后，系统根据“教室可开课程规则”和当天正在使用的上课时间，自动提供 90 分钟时段。

当前默认教室安排：

| 课程 | 默认教室 |
| --- | --- |
| AI | Meeting Room |
| 3D | Meeting Room |
| VEX IQ | VEX IQ Lab |
| VEX V5 | VEX V5 Lab |

如学校以后调整教室用途，可在 `Setup -> Rooms -> Course permissions` 中修改，不需要逐个创建课程。

## 三、管理员使用步骤

1. 打开 `Student`，点击 `New trial student`。
2. 填写新试课学生的基本资料；家长账号可当场关联，也可稍后补充。
3. 为 Session 1 和 Session 2 分别选择科目与日期。
4. 固定课程选择 `Existing class`；AI、3D、VEX IQ、VEX V5 可选择 `Flexible trial slot`。
5. 从系统提供的课程或时段中选择合适安排。
6. 确认两节课没有时间冲突后，点击 `Book trial` 完成登记。

## 四、系统自动保护规则

- 试课登记只用于创建新的试课学生，不会误改现有正式学生。
- 每个试课包包含两节 90 分钟课程。
- 同一学生的两节课不能发生时间重叠。
- 90 分钟课程跨越两个课表时段时，两个时段都会计算占用人数。
- 系统会综合计算该教室内所有重叠的常规学生和试课学生。
- 已满员的时段会明确提示并禁止选择。
- 如果所选灵活时段没有正在进行的常规班级，系统会显示 `Teacher confirmation needed`，提醒管理员先确认老师。
- 灵活试课不会自动生成长期、重复的空课程，因此不会在主课表中产生多余课程卡片。

## 五、完成登记后的展示

- `Daily Schedule`：显示试课学生、课程、时间，并以紫色区分试课状态。
- `Weekly Overview`：校长可以在一周概览中查看试课安排和教室占用。
- `Classroom for iPad`：老师端可看到当天进入教室的试课学生。
- 点击课表中的试课学生姓名，可直接进入该学生详情页。
- 学生详情页会显示完整的两节试课安排；如登记错误，可取消整个试课包。

## 六、当前状态

该功能已完成本地轻量测试，并于 2026 年 9 月 21 日更新至 AWS。上线后已确认系统服务、数据库迁移、公开页面及灵活时段查询正常；本次发布只更新程序和数据库结构，没有导入或覆盖本地测试数据。

功能现已包含固定班级试课、灵活时段试课、90 分钟跨时段占位、重复时间拦截、满员提示、课表展示及学生详情跳转。现阶段建议先在学校内部试运行，根据管理员和老师的实际使用反馈，再完善操作提示及教师确认流程。
